免费用 Claude Code ？

最近各大技术群里都在传一个「不花钱也能用 Claude Code」的骚操作，核心其实就是 AnyRouter 这个中转平台。下面把完整流程拆给你，照着做就能免费薅 API 额度。

先上车：注册 AnyRouter

  • 官网：anyrouter.top
  • 建议用 GitHub 一键登录，省事。
  • 直接注册送 50 美元，走邀请链接能多拿 50 美元，凑够 100 美元，够你写几万行代码
    我的邀请链接：https://anyrouter.top/register?aff=b0LN

领key：生成 API Token

  • 登录后点「API 令牌」→「添加令牌」。
  • 名称随意写，比如「claude-free」。
  • 模型限制可以选 claude-sonnet-4-20250514，也可以留空。
  • 务必勾「无限额度」，不然一次对话就报销。
  • 复制以 sk- 开头的那串字符，待会儿要用。

装 Claude Code

  • Windows 记得开 WSL；macOS / Linux 直接终端。
  • 保证 Node.js ≥ 18：
  • 网络节点优先新加坡或美国，稳。

配环境变量（二选一）

临时方案：每次开终端都要敲

永久方案：写进 shell 配置，一次搞定

  • Bash：~/.bashrc
  • Zsh：~/.zshrc
    把上面两行粘进去，保存后 source ~/.zshrc 或者重开终端。

开干

  1. 进项目目录：claude
  2. 首次启动会提示选主题、确认安全须知、信任目录，一路回车即可。
  3. 输入 /init 初始化，之后就可以用自然语言指挥它写代码了，例如： 它就会自动创建文件、装依赖、跑 dev server。

额度 & 模型小贴士

  • 简单需求（小工具、页面）≈ 0.2 美元一次。
  • 日常用 Sonnet 就够；遇到复杂逻辑，对话里 /model 切成 Opus。
  • 额度见底？拉人头：每邀请一位，双方再得 50 美元。

避坑指南

  • 网络抽风：先重启 claude；实在不行换节点。
  • 代码安全：改关键文件前 git commit 一下，AI 翻车能回滚。
  • 隐私雷区：AnyRouter 会留存上下文，别拿它撸涉密代码。

写在最后
